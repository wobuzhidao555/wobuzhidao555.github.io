03

AI管线 · 视觉语言模型

BLIP-2 + CLIP + Phi-3 · 端侧推理
A
图像理解 BLIP-2 蒸馏模型 · ~300M参数 · ONNX INT8
ViT-B视觉编码器 → FlanT5-small语言解码 → 生成自然语言描述
输入: 拍摄图片 → 输出: "一根点燃的白色蜡烛，火焰摇曳，暖黄色光"
提取语义标签集合: [蜡烛, 火焰, 暖, 黄色, 光]
B
语义匹配 CLIP ViT-B/32 · 150M参数 · 实时200ms刷新
图像嵌入(512维) × 8种真髓文本嵌入 → 余弦相似度 → Softmax归一化
[0.72燃, 0.08流, 0.03固, 0.05锋, 0.02生, 0.01鸣, 0.06映, 0.03虚]
Top-1 = 真髓类型(燃)，概率值 = 匹配度(72%)
C
视觉特征 OpenCV · K-Means + LBP + Laplacian
颜色调色板(5主色) → 碎片配色 · 纹理特征(LBP) → 碎片纹样
图像质量(清晰度+亮度+构图+色彩丰富度) → 品质分(0-100)
品质 = 图像质量分 × 匹配度 → S(90+) / A(75+) / B(60+) / C(<60)
D
碎片命名 Phi-3-mini · 3.8B · ONNX INT4 · 离线
输入: BLIP描述("蜡烛·火焰·暖黄") + 真髓("燃") + 品质(S)
输出: 【燃·烛心焰】 · 持续灼烧 · 微光照明
每枚碎片的名称独一无二——基于你拍的照片内容生成，两个玩家永远不会有相同收藏
分级推理策略：实时预览仅用CLIP(15ms/帧) → 快门触发BLIP-2蒸馏(300ms) → 后台Phi-3命名(500ms) · 总延迟<1s · 全部端侧推理，原图即取即弃，隐私零风险

机制：每个格子需要对应真髓类型的碎片投掷点亮
正确：格子爆开彩光，Boss掉血
错误：格子喷出黑刺，你掉血
全部点亮：Boss窗完全照亮 → 净化（非击杀）
核心张力：4个碎片槽 vs 8种需求 → 战斗中紧急切鉴光模式拍照

战斗策略

预拍策略：进Boss房前预拍8种真髓备用，但只有4个槽位，必须取舍
融合策略：融合碎片覆盖两种类型（焰刃=燃+锋），4槽覆盖8种需求的一半
紧急拍照：Boss攻击间隙切换鉴光模式，在现实中紧急拍照——时间减速0.5×，3秒安全窗口
观察弱点：Boss攻击模式暗示格子需求顺序，先点亮的关键格子会暴露更多弱点
守卫不是敌人：它们是被囚的真髓。净化不是杀死——是释放。叙事与机制合一
"我需要'鸣'，但没带——赶紧拍音箱！"
→ 在Boss暗影弹幕飞来的同时，你切到鉴光模式，举着手机找音箱

故事弧 · 琉璃大教堂

六层攀升 · 一个关于占有与释放的故事
入
大厅
最后的光 — 教堂入口大厅，最后一盏琉璃灯在灭与不灭之间。你举起鉴光镜，镜中映出你的脸——和脸背后无穷的黑暗。该上楼了。
一
地宫
四元 — 最基础的真髓：燃·流·固·锋。教程关。守卫是一尊裂开的石天使，翅膀琉璃碎了。你给它补上"固"，翅膀愈合。
二
花园
百草 — 琉璃花圃全枯。拍植物让琉璃花重新开放。守卫是琉璃荆棘，缠住螺旋梯。需要"锋"斩断，但荆棘会再生——先封"药"解毒根。
三
武库
百炼 — 琉璃兵器陈列室，每件兵器锁着战争记忆。守卫是碎裂琉璃盾，弹回一切攻击。拍一面现实镜子，让盾看见自己的裂痕——它崩溃了。
四
万兽
灵笼 — 琉璃动物园，灵兽醒不来。有些窗需要你已经拍不到的东西——"奔跑的灵"。你的房间没有马。你拍了自己的腿在跑。AI说：奔跑·运动·力量。够了。
五
观星
天穹 — 穹顶观星台，琉璃星图全灭。守卫是"熄灭使者"——纯黑暗构成的影子，碎片穿过无效。你拍了一面关掉的屏幕。AI说：虚·无·镜。黑暗的镜子。你把暗弹回去。
终
天窗
鉴明之室 — 师傅封印的天窗。留言："熄灭不是死亡——是越狱。你一路打败的守卫不是怪物，是囚徒。它们只是想出去。现在你选：重新封印，还是打碎天窗？"
07

三结局 · 占有与释放

你做了一整局的力量，终章要你全部放弃——你愿意吗？
A

封印

你修复天窗。教堂大亮，万窗齐鸣。你成为新任织光者大师。但夜里你听见窗户里传来哭声。你知道，千年后还会有人走到这里，面对同样的选择。

B

解放

你举起鉴光镜，对准天窗中心，用力一砸。千扇窗同时碎裂。无数真髓化为流光飞向世界。教堂在光中坍塌。你抬头——天亮了。真正的日出。不是琉璃的光，是太阳的。

C · 隐藏

传承

你既不封印也不打碎。你把鉴光镜嵌进天窗中心。教堂不再是监狱，变成镜子。万物来此照见自己的真髓，然后自由离开。你在师傅留言旁刻下："光不该被 owned。光该被 seen。"

"徒弟，如果你走到这里，说明我已经不在了。
熄灭的真相是：我们错了。
千年来我们捕捉真髓、封入琉璃、永不释放。
真髓不是燃料，是生命。你把生命关进玻璃千年，它会疯。
那些你一路打败的守卫，不是怪物，是囚徒。它们只是想出去。"

—— 鉴明 · 最后的织光者

铅条(Lead Came)：所有色块用 #0A0A0A 粗黑线分割（2-4px），转角处有焊点。这是彩绘玻璃最核心的视觉特征——没有铅条就不是彩绘玻璃。
光效：琉璃碎片自带内发光(colored glow)；点亮的窗户从背面透光(radial-gradient)；黑暗区域绝对的黑——对比极致。你拍的照片通过AdaIN风格迁移+Voronoi铅条分割→变成独一无二的琉璃碎片。

风险与对策

拥抱不确定性 = 游戏特色
风险严重度对策
摄像头不可用高图库模式(选本地图片) + 预设模式(50张内置图)；核心体验降级但不崩溃
AI识别不准高拥抱不确定性=游戏特色；拍灯被识别成"映"而不是"燃"？你得到了意外碎片！创造惊喜不是bug
隐私担忧高全本地推理；原图即取即弃；人脸检测提示；云端增强可选且只发特征向量
玩家不知道拍什么中真髓雷达(显示环境真髓分布)；提示系统("这扇窗需要燃烧…你的周围有火吗？")
Boss战紧急拍照太仓促中切换时时间减速0.5×；拍照有3秒安全窗口；预拍碎片备用
玩家环境太单调低任何照片都能得到碎片(纯黑=虚空, 纯白=映射)；品质低但有；鼓励外出拍照
